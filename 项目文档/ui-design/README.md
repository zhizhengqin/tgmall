## 设计 Token 文档模板

请填写 `design-tokens.md`，以下字段是我还原设计稿最需要知道的：

- 主色、辅色、背景色、文字色、分割线色、成功/警告/错误色
- 标题/正文/辅助文字/价格的字体、字号、字重、行高
- 间距尺度（xs / sm / md / lg / xl / 2xl）
- 按钮/卡片/输入框/弹窗的圆角
- 卡片/弹窗/悬浮的阴影值

## 导出建议

- 格式：**PNG**，2x 分辨率即可
- 首页建议额外导出一张**长截图**（完整页面滚动到底）
- 有弹窗/浮层的页面，建议额外导出一张**弹窗打开状态**的截图
