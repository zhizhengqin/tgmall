## 1. 色彩系统 (Color Palette)

| Token | 用途 | 值 (OKLCH) | 参考 HEX |
|-------|------|-----------|----------|
| `--bg` | 页面背景 | `oklch(98.5% 0.003 95)` | `#fafaf8` |
| `--surface` | 卡片/面板背景 | `oklch(100% 0 0)` | `#ffffff` |
| `--fg` | 主文字色 | `oklch(20% 0.015 80)` | `#2d2b28` |
| `--muted` | 辅助文字色 | `oklch(50% 0.012 80)` | `#7a7670` |
| `--border` | 分割线/边框 | `oklch(90% 0.005 95)` | `#e8e6e2` |
| `--accent` | 主品牌色（柬埔寨金） | `oklch(64% 0.16 82)` | `#c4932a` |
| `--accent-red` | 价格/促销/错误 | `oklch(52% 0.20 24)` | `#c43a30` |
| `--accent-green` | 成功/库存充足 | `oklch(58% 0.16 155)` | `#2d9d5a` |
| `--accent-blue` | 链接/信息 | `oklch(58% 0.16 255)` | `#3b82d6` |

### 色彩用法规则

- **主品牌金色** (`--accent`): 仅用于 Logo、主按钮、选中态、品牌标识 — 每屏 ≤ 2 处
- **红色** (`--accent-red`): 价格数字、促销标签、删除/取消操作、错误提示
- **绿色** (`--accent-green`): 支付成功、库存充足、确认操作
- **蓝色** (`--accent-blue`): 文本链接、快递追踪状态
- **禁止使用**: 暖色米色/桃色/粉色/橙棕色页面底色（避免 AI 味）

## 2. 字体系统 (Typography)

### 字体族

| Token | 用途 | 字体栈 |
|-------|------|--------|
| `--font-khmer` | 高棉语 UI | `'Noto Sans Khmer', 'Khmer OS', system-ui, sans-serif` |
| `--font-display` | 英文/中文 展示标题 | `-apple-system, BlinkMacSystemFont, 'SF Pro Display', system-ui, sans-serif` |
| `--font-body` | 英文/中文 正文 | `-apple-system, BlinkMacSystemFont, 'SF Pro Text', system-ui, sans-serif` |

### 字号层级

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| H1 / 页面标题 | `19–22px` | 700 | 页面大标题 |
| H2 / 区块标题 | `16–18px` | 600 | section header |
| H3 / 卡片标题 | `14–15px` | 500–600 | 商品名、模块标题 |
| Body | `13–14px` | 400 | 正文、描述 |
| Caption | `11–12px` | 400 | 辅助信息、时间戳 |
| Price | `15–18px` | 700 | 价格（加粗突出） |
| Logo | `19px` | 700 | 品牌标识 |

### 行高

- 标题: `1.3` — 紧凑有力
- 正文: `1.5` — 舒适阅读
- 辅助: `1.4`

### 字间距

- 标题/Logo: `-0.02em`（Software-native 收紧感）
- 正文: 默认
- 价格: `-0.01em`（数字更紧凑）

## 5. 阴影 (Shadow)

| Token | 值 | 用途 |
|-------|-----|------|
| `--shadow-card` | `0 1px 3px oklch(0% 0 0 / 0.06)` | 默认卡片 |
| `--shadow-float` | `0 4px 16px oklch(0% 0 0 / 0.10)` | 弹窗、浮层、导航栏 |

**原则**: hairline borders 为主，阴影仅用于浮层 — 不做大阴影卡片堆叠。

## 7. 图标与插画

- 图标: SVG 内联，24×24 为主
- 商品图片: 4:3 比例占位，等待真实产品图替换
- 状态图标: 成功 ✓ / 警告 ⚠ / 信息 ℹ（无 Emoji 装饰风格）

## 8. 交互状态

| 状态 | 效果 |
|------|------|
| 按钮 Hover | `opacity: 0.9` + 轻微缩放 |
| 按钮 Active | `scale(0.97)` 按压反馈 |
| 卡片 Tap | 背景色 `--bg` 临时高亮 |
| 输入框 Focus | 边框色从 `--border` → `--accent` |
| 导航选中 | 图标 + 文字同变 `--accent` |

---

## 9. 三语设计规则

1. **默认语言**: ភាសាខ្មែរ（高棉语），首次加载不混排
2. **切换行为**: 点击语言按钮后，所有 `[data-i18n]` 元素更新为该语言
3. **字体联动**: 高棉语时 `body` 切换为 `--font-khmer`
4. **价格货币**: USD/KHR 双币种，价格数字使用 `--font-body`（不受高棉字体影响）
5. **禁止混排**: 同一页面不可同时出现多语文本
