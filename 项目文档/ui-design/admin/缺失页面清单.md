# 平台后台 (Admin Web) — 待设计

| 序号 | 文件名 | 页面描述 | 优先级 |
|------|--------|----------|--------|
| A1 | 平台大盘 | 全平台 GMV、商品数、用户数、订单趋势、品类分布 | 中 |
| A2 | 商品管理 | 商品表格（搜索/筛选/批量上下架）+ 新增/编辑商品表单 + 库存管理 | 高 |
| A3 | 订单管理 | 订单表格（状态筛选/批量处理/导出）+ 物流发货 + 售后处理 | 高 |
| A4 | 系统配置 | 费率设置、配送区域、支付渠道、公告管理、运营人员权限 | 低 |
