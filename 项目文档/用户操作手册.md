## 一、消费者操作指南

### 1.1 进入商城

在 **Telegram** 中搜索 **@xhzmall_bot**，点击底部「🛒 ចូលទៅហាង」按钮进入 Mini App。

也可以扫描以下链接生成的 QR 码：
```
https://tgmall-production.up.railway.app/go
```

### 1.2 首页浏览

![首页](./images/consumer-home.png)

| 区域 | 说明 |
|------|------|
| 顶部搜索栏 | 点击进入搜索页，支持历史记录与防抖搜索 |
| 语言按钮 | **中 / ខ / EN** 切换界面语言 |
| 登录引导横幅 | 未登录用户顶部显示，点击跳转登录，24 小时内关闭不再展示 |
| Banner 轮播 | 后台配置的促销 Banner，支持城市定向与时间排期，最多 5 张 |
| 品类横滑 | 全部 / 时尚 / 美妆 / 电子 / 家居等后台配置品类 |
| 限时专区 | 展示后台配置的闪购/低价商品，含倒计时与进度条 |
| 商品网格 | 双列展示，无限滚动 |
| 底部导航 | 首页 / 分类 / 购物车 / 订单 / 我的 |

### 1.3 城市选择

首次进入会提示选择配送城市（如金边 / 暹粒），也可在「我的 → 城市」手动切换。

- 城市选择会影响：首页 Banner、运费、起送金额、预计配送天数
- 支持 GPS 自动定位（需授权）和 Telegram 定位

### 1.4 分类浏览

![分类页](./images/consumer-category.png)

- 左侧 88px 一级分类侧边栏，点击切换分类
- 右侧顶部排序栏：最新 / 价格从低到高 / 价格从高到低 / 销量
- 商品展示支持 **网格视图** 与 **列表视图** 切换，偏好自动保存
- 切换分类或排序自动重载，向下滑动无限加载

### 1.5 商品详情

- 图片轮播浏览
- 规格联动：选择不同规格自动更新价格与库存
- 三语商品描述
- 点击 ♡ 收藏商品
- 点击 ⊕ 快捷加入购物车

### 1.6 登录与注册

支持三种登录方式：

| 方式 | 说明 |
|------|------|
| Telegram 一键登录 | 点击即可用当前 Telegram 账号授权登录 |
| 手机号 + 验证码 | 输入 +855 开头的柬埔寨手机号，获取 6 位短信验证码登录 |
| 手机号 + 密码 | 已设置密码的用户可直接用密码登录 |

**忘记密码**：在登录页点击「忘记密码」→ 验证码验证 → 设置新密码（新密码不能与历史密码重复）。

### 1.7 购物流程

1. **浏览商品** → 点击进入详情页
2. **加入购物车** → 可调整数量；商品详情页点击 ⊕ 可快捷加购
3. **底部购物车条** → 购物车非空时底部显示合计金额、件数 badge 与结算按钮
4. **去结算** → 选择地址 + 优惠券 + 支付方式
5. **提交订单** → 进入支付页面
6. **支付** → KHQR 扫码 / ABA Pay / Wing Pay / COD 货到付款

**结算页说明**：
- 地址选择弹窗内可直接新增收货地址
- 优惠券弹窗按最低消费与有效期过滤，选择后自动计算优惠
- 配送费用按城市规则计算，同时显示 USD / KHR 双币种
- 若未达起送金额，结算按钮显示「还差 $X 起送」

### 1.8 订单追踪

![订单列表](./images/consumer-orders.png)

Tab 切换：全部 / 待付款 / 已确认 / 已付款 / 已发货 / 已完成 / 已取消。

- 待付款订单可继续支付或取消
- 已发货订单可查看物流公司与运单号
- 在线支付订单发货 7 天后自动确认收货
- COD 订单付款后 7 天后自动确认收货

### 1.9 个人中心

![个人中心](./images/consumer-profile.png)

| 功能 | 说明 |
|------|------|
| 我的订单 | 查看所有订单 |
| 收货地址 | 管理配送地址，关联城市 |
| 优惠券 | 领取和查看我的优惠券 |
| 收藏商品 | 查看已收藏商品，下架商品会标记 |
| 客服与反馈 | 联系客服 Telegram / 电话，或提交意见反馈（可上传图片） |
| 城市 | 切换配送城市 |
| 语言设置 | 中 / ភាសាខ្មែរ / English |

### 1.10 支付结果

支付完成后展示结果页，支持状态：成功 / 失败 / 超时 / 取消 / COD 待付款。

## 二、管理后台操作指南

### 2.1 登录

浏览器打开：
```
https://tgmall-production.up.railway.app/admin/
```

![管理后台登录](./images/admin-login.png)

支持两种登录方式：
- **账号密码登录**：输入用户名和密码
- **手机验证码登录**：输入管理员手机号，获取 OTP 验证码登录

> 默认账号：`admin`，密码由管理员在 Railway 环境变量 `ADMIN_PASSWORD` 中设置（bcrypt 哈希）。

### 2.2 数据看板

左侧菜单 → **数据看板**：

| 模块 | 说明 |
|------|------|
| 今日收入 | 当日 GMV 与订单数 |
| 待处理订单 | 待付款 / 待发货订单数 |
| 7 天趋势图 | 近 7 天 GMV 走势 |
| 支付成功率 | 在线支付成功订单占比 |
| 品类销售占比 | 饼图展示各品类销售额 |
| TOP 10 商品 | 销售额最高的 10 个商品 |

### 2.3 商品管理

左侧菜单 → **商品管理**：

| 操作 | 说明 |
|------|------|
| 查看列表 | 表格展示名称、USD/KHR 价格、库存、状态 |
| 添加商品 | 填写三语名称/价格/库存/图片/规格/标签，点击发布 |
| 编辑商品 | 点击编辑进入表单 |
| 上/下架 | 开关切换 |

**添加商品字段**：

| 字段 | 说明 |
|------|------|
| 名称 (高棉语) | ឈ្មោះ ជាភាសាខ្មែរ |
| 名称 (英语) | Name in English |
| 名称 (中文) | 名称 (中文) |
| USD 价格 | 美元标价 |
| KHR 价格 | 瑞尔标价 |
| 库存 | 可售件数 |
| 品类 | 时尚/美妆/电子/家居等后台配置品类 |
| 图片 | 支持粘贴图片 URL 或本地上传压缩后的图片 |
| 规格 (SKU) | 添加规格名/值/价格/库存，不同规格独立定价与库存 |
| 标签 | 从标签库选择，最多 6 个；支持自定义三语标签文本与颜色 |

### 2.4 库存管理

左侧菜单 → **库存管理**：

| 操作 | 说明 |
|------|------|
| 库存列表 | 查看各商品当前库存与预警阈值 |
| 库存调整 | 对指定商品增加或减少库存，填写原因 |
| 库存盘点 | 批量盘点，校正实际库存 |
| 变更日志 | 查看所有库存调整记录 |
| 预警阈值 | 设置商品库存低于多少时预警 |
| CSV 导出 | 导出库存数据 |

### 2.5 订单管理

左侧菜单 → **订单管理**：

| Tab | 说明 |
|-----|------|
| 全部 | 所有订单 |
| 待付款 | 等待消费者付款 |
| 已确认 | COD 订单，等待发货 |
| 已付款 | 待发货 |
| 已发货 | 运输中 |
| 已完成 | 交易完成 |
| 已取消 | 已取消订单 |

**订单操作**：
- 点击订单查看详情
- 已付款 / 已确认（COD）订单 → 填写物流公司和运单号 → 确认发货
- COD 订单现金收款后 → 点击「确认收款」完成订单
- 支持按状态/日期筛选后 **导出 CSV**

### 2.6 优惠券管理

左侧菜单 → **优惠券管理**：

| 操作 | 说明 |
|------|------|
| 列表 | 查看所有优惠券 |
| 新增 | 设置标题（三语）、类型（固定金额/百分比）、面值、最低消费、总量、有效期 |
| 编辑 | 修改优惠券信息 |
| 启用/停用 | 控制优惠券是否可领取 |

> 创建时结束时间必须晚于开始时间。

### 2.7 运营配置

左侧菜单 → **运营配置**，包含 5 个子模块：

| 子模块 | 说明 |
|--------|------|
| Banner 管理 | 首页轮播图 CRUD，支持跳转类型、城市定向、生效时间 |
| 品类管理 | 商品分类 CRUD，支持三语名称、图标、排序 |
| 城市管理 | 配送城市 CRUD，支持经纬度、启用/禁用、排序 |
| 配送规则 | 按城市配置起送金额、运费、免邮门槛、预计送达天数 |
| 客服账号 | 配置客服 Telegram 链接、电话、在线时间 |

### 2.8 系统配置

左侧菜单 → **系统配置**：

| 子模块 | 说明 |
|--------|------|
| 平台设置 | 商城名称、Logo、联系方式、维护模式、公告、登录引导横幅图片 |
| 管理员账号 | 增删改管理员、重置密码、启用/禁用、角色分配（admin/operator/cs/warehouse） |

### 2.9 用户管理

左侧菜单 → **用户管理**：

- 搜索、查看已注册消费者
- 点击用户查看详情：基本信息、订单数量、累计消费
- 支持禁用/启用用户账号

### 2.10 反馈管理

左侧菜单 → **反馈管理**：

- 查看消费者提交的意见反馈
- 支持按状态筛选（待处理 / 已处理）
- 点击可查看详情与上传的图片
- 标记反馈为「已处理」

### 2.11 限时专区

左侧菜单 → **限时专区**：

- 选择参与专区的商品
- 设置专区价格、专区库存、适用城市、开始/结束时间
- 首页会自动展示生效中的专区商品

### 2.12 商品标签

左侧菜单 → **商品标签**：

- 标签库 CRUD：高棉语 / 英语 / 中文文本、颜色、背景色、排序
- 创建商品时可直接从标签库选择标签

## 三、常见问题

| 问题 | 解决 |
|------|------|
| 管理后台白屏 | URL 后加 `?v=2` 绕过 CDN 缓存 |
| 忘记密码 | Railway → Variables → 修改 ADMIN_PASSWORD，重新部署 |
| 商品不显示 | 检查商品状态是否为"上架"、库存 > 0、所属城市是否匹配 |
| Mini App 打不开 | 确保在 Telegram App 内打开，非浏览器 |
| 语言切换不生效 | 关闭 Mini App 重新打开 |
| 首页 Banner 不显示 | 检查 Banner 是否已启用、当前城市与时间是否在生效范围内 |
| 运费不对 | 检查用户选择的城市与配送规则配置是否一致 |
| 优惠券领取失败 | 检查优惠券是否已启用、总量是否已领完、是否满足最低消费 |
| 订单 CSV 导出一行 | 检查筛选条件是否正确 |
