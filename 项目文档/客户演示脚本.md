## 二、消费者端演示流程（Telegram Mini App）

**目标**：让客户体验“浏览 → 加购 → 下单 → 支付/到货”完整闭环。

### 2.1 进入商城（约 2 分钟）

1. 在 Telegram 顶部搜索框输入 `@xhzmall_bot`。
2. 点击进入 Bot 聊天窗口，点击底部按钮 **「🛒 ចូលទៅហាង」** 进入 Mini App。
3. **讲解点**：
   - “这是基于 Telegram 的电商小程序，用户无需下载独立 App。”
   - “打开速度快，适合柬埔寨 Telegram 用户的使用习惯。”

### 2.2 城市选择与首页（约 3 分钟）

1. 首次进入会弹出城市选择，选择 **金边（Phnom Penh）**。
2. 进入首页，依次向客户展示：
   - 顶部搜索栏
   - 语言切换按钮（中 / ខ / EN）
   - 登录引导横幅（未登录时顶部出现）
   - **Banner 轮播**：3 张促销图，支持城市定向
   - **品类横滑**：时尚 / 美妆 / 电子 / 家居 / 食品
   - **限时专区**：蓝牙耳机、口红、咖啡豆闪购
   - **商品双列网格**：12 个商品，带标签和价格
3. **讲解点**：
   - “所有价格都同时显示 USD 和 KHR，方便本地消费者。”
   - “城市会影响 Banner、运费和起送金额，后台可配置。”

### 2.3 商品详情与加购（约 4 分钟）

1. 点击 **「无线蓝牙耳机」**（$28）进入详情页。
2. 展示：
   - 商品图片轮播
   - 三语商品名称与描述
   - 标签：热销、爆款
   - 规格选择：白色 / 黑色，价格联动
   - 收藏按钮 ♡ 和快捷加购 ⊕
3. 选择 **黑色**，点击 **「加入购物车」**。
4. **讲解点**：
   - “规格和库存是联动的，不同颜色/尺码价格可不同。”
   - “商品标签、库存预警都在后台统一配置。”

### 2.4 分类浏览与列表切换（约 2 分钟）

1. 点击底部 **「分类」** Tab。
2. 左侧选择 **美妆**，右侧展示美妆商品。
3. 切换排序：**最新 / 价格从低到高 / 价格从高到低 / 销量**。
4. 点击右上角切换 **网格视图 / 列表视图**。
5. **讲解点**：
   - “分类和排序支持后台配置，网格/列表偏好会自动记住。”

### 2.5 登录（约 2 分钟）

1. 在“我的”页面点击 **登录**。
2. 展示三种登录方式：
   - **Telegram 一键登录**（推荐，演示使用）
   - 手机号 + 验证码
   - 手机号 + 密码
3. 点击 **Telegram 一键登录**，授权后即可登录。
4. **讲解点**：
   - “Telegram 用户一键授权，无需注册，降低流失。”
   - “手机号登录支持短信验证码，适合非 Telegram 场景。”
   - *注意：手机号验证码演示需确认短信通道可用；如遇收不到码，改用 Telegram 登录。*

### 2.6 购物车与结算（约 4 分钟）

1. 进入 **购物车**，显示已加入的蓝牙耳机。
2. 调整数量为 2，观察合计金额变化。
3. 点击 **去结算**。
4. 在结算页展示：
   - 地址选择（可新增收货地址）
   - 优惠券选择：选择 **满 $20 减 $5**
   - 配送费用：金边 $1.00
   - 起送提示：如金额不足会提示“还差 $X 起送”
   - 实付金额 USD / KHR 双币种显示
5. **讲解点**：
   - “优惠券按最低消费自动过滤，选择后实时计算优惠。”
   - “配送费和免运费门槛按城市后台配置。”

### 2.7 下单与支付（约 3 分钟）

1. 选择 **货到付款（COD）** 支付方式，点击 **提交订单**。
2. 进入订单详情页，展示订单号和订单状态。
3. **讲解点**：
   - “目前支持 KHQR 扫码、ABA Pay、Wing Pay 和 COD 四种支付方式。”
   - “线上支付会跳转对应支付页面；COD 由后台确认后发货。”
   - *注意：真实支付通道演示前请确认已对接；当前可用 COD 做安全演示。*

### 2.8 订单追踪（约 2 分钟）

1. 进入 **我的 → 我的订单**。
2. 切换 Tab：全部 / 待付款 / 已付款 / 已确认 / 已发货 / 已完成 / 已取消。
3. 点击一个 **已发货** 订单，查看物流公司和运单号。
4. **讲解点**：
   - “订单状态全链路可追踪，后台可手动推进状态。”
   - “演示数据中已预置 8 个不同状态的订单。”

### 2.9 优惠券与收藏（约 2 分钟）

1. 进入 **我的 → 优惠券中心**，展示已领取的优惠券。
2. 领取一张新的优惠券。
3. 进入 **我的 → 收藏**，展示之前收藏的商品。
4. **讲解点**：
   - “优惠券可在后台创建，支持固定金额、百分比、免运费等类型。”
   - “收藏功能提升复购率。”

### 2.10 客服与反馈（约 1 分钟）

1. 在商品详情或“我的”页面点击 **客服**。
2. 跳转 Telegram 客服账号 `@xhzmall_support`。
3. 进入 **意见反馈**，提交一条反馈。
4. **讲解点**：
   - “客服入口直连 Telegram，符合本地用户习惯。”
   - “反馈工单可在后台统一处理。”

## 三、管理后台演示流程

**目标**：让客户看到平台运营方如何管理商品、订单、优惠和运营配置。

### 3.1 登录后台（约 2 分钟）

1. 电脑浏览器打开 `https://tgmall-production.up.railway.app/admin/`。
2. 输入用户名 `admin` 和对应密码登录。
3. **讲解点**：
   - “后台支持用户名密码登录和管理员手机号 OTP 登录。”
   - “后续可配置二级权限，区分运营、客服、财务角色。”

### 3.2 数据看板（约 2 分钟）

1. 登录后进入首页 Dashboard。
2. 展示关键指标：今日订单、今日销售额、待处理订单、商品库存预警等。
3. **讲解点**：
   - “看板数据实时更新，帮助运营快速掌握业务状态。”
   - “库存预警商品会高亮提醒，避免超卖。”

### 3.3 商品管理（约 5 分钟）

1. 进入 **商品管理 → 商品列表**。
2. 展示 12 个演示商品，说明搜索、分类筛选、状态筛选。
3. 点击 **男士运动跑鞋** 进入编辑页：
   - 修改三语名称/描述
   - 上传/替换商品图片
   - 编辑规格：颜色、尺码、对应库存与差价
   - 设置库存预警值
   - 绑定商品标签
   - 选择分类
4. 点击 **新增商品**，演示新增流程（可不保存）。
5. **讲解点**：
   - “商品支持多规格、多语言、多图展示。”
   - “库存预警值可设置，低于阈值会在看板提醒。”

### 3.4 订单管理（约 4 分钟）

1. 进入 **订单管理 → 订单列表**。
2. 展示 8 个演示订单，按状态筛选：
   - 待付款
   - 已付款（待发货）
   - 已确认（COD 待发货）
   - 已发货
   - 已完成
   - 已取消
3. 点击一个 **COD 已确认** 订单，演示：
   - 查看订单详情、商品、地址、支付信息
   - 点击 **发货**，填写物流公司和运单号
   - 状态变为“已发货”
4. 演示 **CSV 导出** 功能。
5. **讲解点**：
   - “订单状态支持手动推进，COD 订单确认后发货。”
   - “订单数据可导出 CSV，方便财务对账。”

### 3.5 库存管理（约 2 分钟）

1. 进入 **库存管理 → 库存列表**。
2. 选择一个商品，点击 **调整库存**。
3. 输入调整数量、原因、备注，保存后查看库存日志。
4. **讲解点**：
   - “所有库存变更都有日志记录，便于追溯。”
   - “支持定期盘点，对比系统库存与实际库存。”

### 3.6 优惠券管理（约 2 分钟）

1. 进入 **营销 → 优惠券**。
2. 展示 4 张演示优惠券：满减 / 折扣 / 免运费。
3. 点击 **新建优惠券**，演示设置：
   - 三语标题
   - 优惠类型与面额
   - 最低消费金额
   - 发放总量与有效期
4. **讲解点**：
   - “优惠券可针对全平台或特定城市发放。”
   - “领取与使用数据可实时查看。”

### 3.7 运营管理配置（约 3 分钟）

1. **Banner 管理**：展示 3 张 Banner，说明城市定向与时间排期。
2. **分类管理**：展示 5 个分类，说明图标、排序、启用/禁用。
3. **城市与配送**：展示 3 个城市及其配送规则（起送金额、运费、免运费门槛、预计天数）。
4. **限时专区**：展示 3 个闪购商品，说明特价、库存、倒计时。
5. **客服账号**：展示默认客服 `@xhzmall_support`。
6. **讲解点**：
   - “首页所有模块都可在后台配置，无需改代码。”
   - “城市配送规则灵活，支持不同城市的差异化运营。”

### 3.8 用户与反馈管理（约 2 分钟）

1. 进入 **用户管理 → 用户列表**，展示 3 个演示用户。
2. 点击用户查看详情、地址、订单、优惠券。
3. 进入 **客服 → 反馈工单**，展示 3 条反馈。
4. 点击一条待处理反馈，演示 **标记为已解决**。
5. **讲解点**：
   - “用户数据与订单、收藏、反馈关联，形成完整画像。”
   - “反馈工单可分配给客服跟进。”

### 3.9 系统设置（约 1 分钟）

1. 进入 **系统设置**。
2. 展示：店铺名称（三语）、汇率、登录 Banner、公告（三语）。
3. **讲解点**：
   - “汇率、店铺名称、公告等全局配置可实时调整。”
   - “当前 USD→KHR 汇率为 4100。”

## 五、常见问题与应急预案

### 5.1 演示中可能遇到的问题

| 问题 | 原因 | 应对 |
|------|------|------|
| Mini App 打不开 | Telegram 缓存或网络 | 重新进入 Bot 对话，再次点击按钮；或刷新页面 |
| 城市选择弹窗没出现 | 已选过城市 | 在「我的 → 城市」手动切换 |
| 手机号验证码收不到 | 短信通道未配置或运营商延迟 | 改用 Telegram 一键登录 |
| 真实支付无法跳转 | 支付通道未完全对接 | 用 COD 货到付款演示下单流程 |
| 后台登录失败 | 密码错误 | 联系技术负责人确认 Railway 环境变量 `ADMIN_PASSWORD` |
| 图片加载慢 | CDN 或网络 | 提前说明“当前为演示环境，正式环境会优化图片” |
| 数据与脚本不一致 | seed 被重复运行或部分覆盖 | 以实际页面展示为准，必要时重新运行 `npm run db:seed:demo` |
