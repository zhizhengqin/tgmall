# 商品管理列表三语名称展示设计

## 背景

运营后台「商品管理」页面（`/admin/products`）的商品列表当前只显示高棉语（柬文）名称，不利于运营人员对照核对中、柬、英三语内容。本设计将列表「名称」列改为同时展示三语名称。

## 目标

- 在商品管理列表的「名称」列同时展示高棉语、英语、中文三语名称。
- 保持列表可读性，缺省语言不展示异常占位。
- 新增单元测试覆盖三语展示与缺省场景。

## 数据模型

后端 `product` 表已包含三语字段：

| 字段      | 含义         | 可空性 |
|-----------|--------------|--------|
| `nameKm`  | 高棉语名称   | 非空   |
| `nameEn`  | 英语名称     | 可空   |
| `nameZh`  | 中文名称     | 可空   |

API `GET /admin/products` 已返回上述三字段，前端无需改动接口。

## UI 设计

采用「多行主次显示」：

- 第一行：高棉语名称，默认字号与颜色，作为主识别信息。
- 第二行：英语名称 + 中文名称，使用较小字号与灰色，中间以 `·` 分隔。
- 缺省处理：
  - 仅 `nameEn` 存在时只显示英文。
  - 仅 `nameZh` 存在时只显示中文。
  - 两者皆空时，副标题整行不渲染。
- 列宽从 `min-width="150"` 调整为 `min-width="180"`，给副标题留足空间。
- 样式写在 `ProductsPage.vue` 的 `<style scoped>` 中，避免影响其他页面。

示例效果：

```
ទំនិញខ្មែរ
English Name · 中文名称
```

## 修改范围

- `tgmall-admin/src/pages/ProductsPage.vue`
- `tgmall-admin/tests/unit/ProductsPage.test.js`（新增）

## 实现要点

1. 将 `el-table-column` 的 `prop="nameKm"` 改为自定义 `template`。
2. 在 `template` 中渲染 `.product-name-km` 与 `.product-name-sub` 两个元素。
3. 使用条件渲染处理 `nameEn` / `nameZh` 的缺省情况。
4. 增加 scoped CSS 控制副标题字号与颜色。

## 测试计划

新增 `ProductsPage.test.js`，覆盖以下场景：

1. 桌面端表格正常渲染。
2. 商品同时存在三语名称时，主标题与副标题均正确渲染。
3. 缺少 `nameEn` 或 `nameZh` 时，不渲染多余分隔符或空文本。
4. `nameEn` 与 `nameZh` 都为空时，只渲染主标题。

## 验收标准

- [ ] 商品列表「名称」列同时显示柬、英、中三语。
- [ ] 任一语言为空时展示不出现异常分隔符或空行。
- [ ] 新增单元测试通过。
- [ ] 不影响现有商品编辑表单及其他页面。
