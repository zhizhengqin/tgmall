# 购物车页面中柬英三语国际化 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 `CartPage.vue` 中的所有硬编码中文替换为 i18n 翻译键，并在 zh/en/km 三个 locale 文件中补充完整翻译。

**Architecture:** 复用现有 `cart` 命名空间，新增 `checkoutCount`、`stockLeft`、`insufficient`、`confirmRemove` 四个键；带变量文案使用 `$t('key', { count: value })`。

**Tech Stack:** Vue 3 + vue-i18n

---

### Task 1: 修改 CartPage.vue 使用 i18n 翻译键

**Files:**
- Modify: `tgmall-miniapp/src/views/CartPage.vue`

- [ ] **Step 1: 替换页面标题、加载、空状态、按钮文案**

将以下文本替换为 `$t()`：
- `购物车` → `$t('cart.title')`
- `加载中...` → `$t('common.loading')`
- `购物车是空的` → `$t('cart.empty')`
- `去逛逛` → `$t('cart.goShopping')`
- `全选` → `$t('cart.selectAll')`
- `合计` → `$t('cart.total')`
- `结算({{ checkedIds.length }})` → `$t('cart.checkoutCount', { count: checkedIds.length })`
- `仅剩 {{ item.maxQuantity }} 件` → `$t('cart.stockLeft', { count: item.maxQuantity })`
- `库存不足!最大 {{ item.maxQuantity }} 件` → `$t('cart.insufficient', { count: item.maxQuantity })`
- `确定删除此商品?` → `$t('cart.confirmRemove')`

- [ ] **Step 2: 构建验证 CartPage.vue 无语法错误**

Run: `cd tgmall-miniapp && npm run build 2>&1 | tail -5`
Expected: `✓ built in ...ms`

- [ ] **Step 3: Commit**

```bash
git add tgmall-miniapp/src/views/CartPage.vue
git commit -m "i18n(cart): CartPage.vue 使用翻译键替换硬编码中文"
```
