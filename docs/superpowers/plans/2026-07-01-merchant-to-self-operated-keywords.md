# 商家概念移除统一替换词表

> 适用范围：`项目文档/` 全局复核，重点修复 `项目文档/产品需求文档_PRD.md`
> 业务背景：V1.0 多商户平台 → V2.0 公司自营模式
> 原则：除历史版本对比（如“V1.0 多商户平台 → V2.0 公司自营模式”）外，不再保留任何商户/商家/merchant/seller/vendor 概念。

## 统一替换词表

| 旧表述 | 新表述 | 说明 |
|--------|--------|------|
| 商家入驻 / 多商户 / 多租户 | 公司自营 | 不再开放第三方入驻，由公司统一运营 |
| 商家后台 / 商家端 | 管理员后台 / 运营后台 / 管理后台 | 无独立商家端，统一由公司运营/管理员使用 |
| 商家审核 | （删除）或改为“平台运营管理” | 公司自营无需审核第三方商家 |
| 商家表 `merchants` | `shop_config` / `platform_settings`（可选） | 如需保留单一平台店铺配置 |
| `merchant_id` / `merchantId` | 删除，或改为 `shop_id` | 自营模式下订单/商品不再关联第三方商家 |
| `/merchant/*` 路由 | `/admin/*` | 统一为管理后台路由 |
| `tgmall-merchant` | `tgmall-admin` | 前端/项目命名 |
| `merchant.xxx.kh` | `admin.xxx.kh` | 管理后台域名 |
| 商家多租户 | 公司自营 | 架构决策变更 |
| merchant / seller / vendor | admin / platform / company | 英文术语统一 |
| 店铺（与商家绑定时） | 平台 / 商城 / 店铺（单一平台店铺） | 仅保留“公司自营店铺”概念 |
| 店铺二维码 / 不同商家不同二维码 | 平台推广二维码 | 删除“按商家分二维码”逻辑 |
| 商家名称 / `merchant_name` | 删除或改为“品牌/平台” | 商品卡片不再展示第三方商家名 |
| 商家服务 | 平台运营服务 / admin service | 测试/模块命名 |
| 商家券 / 本店优惠券 | 平台优惠券 | 优惠券由平台统一发放 |
| 种子商家 | 种子商品 / 试运营商品 | 初期供给端指标 |
| 商户排行榜 | 商品销量排行榜 | 数据大屏指标 |
| 新增商家数 | 新增 SKU 数 / 新增商品数 | 平台运营 KPI |
| 活跃商家数 | 活跃 SKU 数 / 在线商品数 | 平台运营 KPI |
| 商家月留存率 | 商品月动销率 / 平台月活留存率 | 增长指标 |
| 商家能接受 2-5% 佣金模式 | 供应商/货源能支撑平台毛利空间 | 商业模式假设 |
| 商家招募速度 | 商品采购/上架速度 | 供应链风险描述 |
| 金边华人商家兼消费者 | 金边华人消费者 / 华人店主兼消费者 | 用户画像去商家化 |
| 商家批量导入商品 | 运营批量导入商品 | 后台操作描述 |

## 保留不变的内容

以下关键字仅在不被解释为“第三方商家/商户系统”时保留：

- Telegram Bot 名称、外部服务标识（如 `xhzmall_bot`）
- 公开 URL / 域名中未涉及 `merchant` 的部分（如 `api.shop.xinhua-tech.kh`）
- 历史版本对比句（如 `V1.0 多商户平台 → V2.0 公司自营模式`）
